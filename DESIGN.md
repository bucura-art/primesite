**Design System Guidelines (`design.md`)**

### **1. Color Palette**

The color scheme balances warm, soft neutral backgrounds with bold, high-contrast primary accents to create an inviting yet clean visual hierarchy.

| Role | Color Name | Hex Code | Usage Examples |
| --- | --- | --- | --- |
| **Primary Background** | Cream / Warm Oatmeal | `#F9F5EE` | Main page background, section wrappers |
| **Card / Surface Background** | Soft Vanilla | `#FFFDF9` | Product cards, featured item panels |
| **Primary Accent / CTA** | Electric Cobalt Blue | `#0000D0` | Primary buttons (`SHOP ALL COOKIES`), key header text |
| **Secondary Accent** | Slate Navy | `#1F2430` | Main body text, footers, dark subheadings |
| **Callout / Badge Background** | Pale Lavender / Soft Lilac | `#ECEBF8` | Discount tags, category badges ("Best Seller") |
| **Border / Divider** | Muted Sand | `#E8E2D9` | Subtle section dividers, card outlines |

---

### **2. Typography & Hierarchy**

* **Primary Headings (H1–H3):** Rounded, friendly Serif or Display Sans-serif fonts (e.g., *Recoleta*, *Fredoka*, or *Cooper Light*). Keeps headers expressive, approachable, and thick.
* **Body & Navigation:** Clean Geometric Sans-serif (e.g., *Inter*, *DM Sans*, or *Plus Jakarta Sans*). Ensures high readability for menu items, descriptions, and pricing.

---

### **3. UI Components & Layout Guidelines**

* **Buttons:**
* **Primary Button:** Solid Cobalt Blue (`#0000D0`) background with crisp white text. Sharp or slightly rounded corners (4px radius). Hover state slightly lightens or shifts scale (+2%).
* **Secondary Button:** Transparent background with Cobalt Blue border and text. Hover fills background with light blue wash.


* **Product & Feature Cards:**
* Flat elevation or soft, wide drop-shadows (`box-shadow: 0 4px 20px rgba(0,0,0,0.04)`).
* Off-white or light lavender container fills against the warmer cream page background.


* **Spacious Layout:**
* Generous vertical padding between sections (80px–120px) to give high-resolution photography room to breathe.
* Horizontal scrolling cards for featured collections on mobile and desktop viewports.
